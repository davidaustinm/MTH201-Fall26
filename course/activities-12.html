    Worksheet Lab 1, Due: Monday, January 29
    

    Instructions: The exercises here should be completed in groups of 2 or 3 students. You only need to hand in one copy per group, but please include everyone’s name.
    🔗
    There are two aims for this lab. First, I want to introduce you to spreadsheets as a tool for understanding some ideas in calculus. At the beginning of the class, I will demonstrate for you some fundamental things: how to enter data in cells, how to refer to other cells and how to copy information from one cell to another. Second, I would like to review how definite integrals are constructed; namely, I would like for you to think of an integral as a fancy sum.
    🔗

    1.

    (a)

    Remember that if we have a function \(f(x)\text{,}\) we can define the definite integral
    \begin{equation*} \int_a^b f(x)~dx \end{equation*}
    by looking at either left sums \(L_n\) or right sums \(R_n\text{.}\) To form these, we choose some value for \(n\) and define \(\Delta x = \frac{b-a}{n}\) and the points \(x_i=a+i\Delta x\text{.}\) The left and right Riemann sums are
    \begin{align*} L_n\amp=\ampf(x_0)\Delta x + f(x_1)\Delta x + \ldots + f(x_{n-1})\Delta x = \sum_{i=0}^{n-1}f(x_i)\Delta x\\ R_n\amp=\ampf(x_1)\Delta x + f(x_2)\Delta x + \ldots + f(x_{n})\Delta x = \sum_{i=1}^nf(x_i)\Delta x \end{align*}
    The definite integral is then defined as
    \begin{equation*} \int_a^b f(x)~dx =\lim_{n\to\infty}L_n = \lim_{n\to\infty}R_n. \end{equation*}
    🔗
    Let’s now consider the function \(f(x) = x^3\) and the definite integral
    \begin{equation*} \int_0^1 x^3~dx. \end{equation*}
    First off, use the Fundamental Theorem of Calculus to evaluate this integral exactly.
    🔗
    🔗

    (b)

    Set up a Google sheet as shown below to evaluate the Riemann sums with \(n = 10\text{.}\) The first column is \(\Delta x\text{.}\) The second column starts at \(0\) and each subsequent entry is obtained by adding \(\Delta x\) to the entry above. This generates the points \(x_i\text{.}\) The third column is simply the function \(f(x)=x^3\) evaluated at \(x_i\text{.}\) The fourth column will add the terms for the left sum, and the fifth column will add the terms for the right sum. To obtain the entry in one row, simply add the appropriate term \(f(x_i)\Delta x\) to the entry directly above.
    🔗
    A convenient way to set this up is to enter 0.1 for \(\Delta x\) in cell A2, enter ``=A2’’ in cell A3 and copy that entry into the rest of the column. That way, if you change \(\Delta x\) in one place, it will change everywhere.
    🔗

    0.1000 0.0000 0.0000
    0.1000 0.1000 0.0010 0.0000 0.0001
    0.1000 0.2000 0.0080 0.0001 0.0009
    0.1000 0.3000 0.0270 0.0009 0.0036
    \vdots \vdots \vdots \vdots
    🔗
    What do you find for the Riemann sums, \(L_{10}\) and \(R_{10}\text{?}\) Be sure that you have actually included exactly 10 terms in your approximations. State your results with 6 digits after the decimal place.
    🔗
    🔗

    (c)

    Now repeat this using \(n = 100\text{.}\) This corresponds to \(\Delta x = 0.01\text{.}\) If you set up your earlier worksheet well, you should only need to change the entry for \(\Delta x\) in one location. What do you find for the Riemann sums? State your result with 6 digits after the decimal place.
    🔗

    (d)

    Repeat using \(n = 1000\text{.}\) What do you find for the Riemann sums? State your result with 6 digits after the decimal place.

    2.

    The definite integral
    \begin{equation*} \int_0^1e^{-x^2}~dx \end{equation*}
    cannot be evaluated using the Fundamental Theorem of Calculus because there is not an antiderivative that can be found in terms of familiar functions.
    🔗
    Using left and right Riemann sums, give an estimate of this definite integral with an error of no more than \(0.005\text{.}\) Explain how you’ve done this with left and right Riemann sums. Do not evaluate the integral on your calculator to estimate the error.
    🔗
    Note: to evalue an exponential in a spreadsheet, use ``= EXP( ... )’’.
